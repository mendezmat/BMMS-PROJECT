# BMMS Graphics Update 036.0

## Objetivo

Mejorar la operación de Scripture con animaciones configurables y establecer una fuente documental única para las decisiones de producto.

## Cambios

- Presets Clean, Broadcast, Minimal, Typewriter y Sin animación.
- Entrada y salida independientes.
- Duración y easing configurables.
- Transición inteligente del contenido entre versículos del mismo capítulo.
- Previsualización desde el panel de Scripture.
- Documentación oficial de dirección, foco, decisiones y roadmap.

## Compatibilidad

Los estados guardados previamente continúan funcionando mediante valores por defecto.

## Próximo sprint

Validar las animaciones en producción y resolver el siguiente pendiente operativo de Scripture.
