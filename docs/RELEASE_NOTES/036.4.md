# BMMS Graphics 036.4 — Performance Engine

## Objetivo

Reducir consultas, procesamiento y actualizaciones visuales innecesarias durante la sincronización continua con ProPresenter.

## Cambios

- Polling adaptativo: 250 ms con actividad reciente, 1000 ms tras 5 segundos sin cambios y 2000 ms tras 30 segundos.
- Filtro rápido por hash antes de consultar metadatos, normalizar contenido o publicar eventos.
- Las consultas de metadatos de presentación y slide solo se ejecutan cuando cambia el contenido bruto.
- Publicación de telemetría limitada para evitar eventos SSE repetitivos.
- Diagnóstico desacoplado: con el panel cerrado no se actualiza su DOM.
- Registro de duplicados agrupado como una sola entrada acumulada.
- Nuevas métricas: intervalo actual de polling y descartes rápidos por hash.

## Compatibilidad

No se agregaron dependencias. Se mantiene la recuperación después de slides vacíos y la reconexión automática de la Update 036.3.

## Próximo foco

Validar consumo durante una sesión prolongada y luego retomar el gestor avanzado de estilos de Scripture.
