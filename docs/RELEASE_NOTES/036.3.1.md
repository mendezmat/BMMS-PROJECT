# BMMS Graphics 036.3.1 — Diagnostics Hotfix

## Objetivo

Corregir el panel de diagnóstico de ProPresenter que cambiaba visualmente de estado, pero quedaba recortado por la grilla fija del workspace.

## Problema resuelto

El workspace de Scripture tenía tres filas declaradas. Al insertar el panel de diagnóstico como una fila adicional, el editor pasaba a una fila implícita fuera del área visible y el contenedor raíz lo recortaba con `overflow: hidden`.

## Cambios

- Scripture ahora reserva una fila propia para el panel de diagnóstico.
- El panel nativo `<details>` puede abrirse y cerrarse sin JavaScript.
- El contenido abierto tiene altura máxima y desplazamiento interno.
- Se agregó un registro local de los últimos 20 eventos relevantes.
- No se modificó el Live Engine ni su lógica de reconexión.

## Versión

`1.14.5-beta.16`
