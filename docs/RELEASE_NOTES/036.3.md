# BMMS Graphics 036.3 — Live Engine Stability

## Objetivo
Evitar que Scripture se bloquee tras slides vacíos, timeouts o desconexiones temporales de ProPresenter.

## Cambios
- Los slides vacíos reinician la deduplicación; volver al mismo versículo vuelve a actualizar correctamente.
- Reconexión automática después de tres errores consecutivos.
- Backoff progresivo para evitar saturar ProPresenter y la terminal.
- Registro de errores limitado para evitar spam continuo.
- Panel de diagnóstico nativo con `<details>`, independiente del JavaScript de apertura.
- Botón para reiniciar la conexión sin reiniciar BMMS.
- Métricas de slides vacíos, errores consecutivos, reconexiones, última respuesta y último timeout.

## Versión
`1.14.4-beta.15`
