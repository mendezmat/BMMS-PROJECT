# Update 037.1.1 — Smart Flyer Responsive Workspace

## Correcciones

- Smart Flyer ahora ocupa correctamente el área disponible del navegador a 1920×1080 y zoom 100%.
- El encabezado, el workspace y las propuestas broadcast usan una cuadrícula vertical acotada.
- Fuente, preview e inspector tienen desplazamiento independiente sin recortar contenido.
- El preview dejó de depender de una posición sticky que interfería con la altura disponible.
- Las propuestas broadcast son más compactas y permanecen visibles en la parte inferior.
- Se añadió una alternativa de scroll general para viewports de poca altura.

## Compatibilidad

No se modificó Scripture, ProPresenter Live Link, OCR, QR ni el modelo de Smart Flyer.
