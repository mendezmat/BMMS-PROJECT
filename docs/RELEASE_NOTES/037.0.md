# BMMS Graphics 037.0

## Objetivo

Iniciar Smart Flyer sobre una base funcional y extensible sin modificar Scripture, que queda en mantenimiento.

## Cambios

- activación del módulo Smart Flyer en la navegación;
- carga y preview local de imágenes;
- análisis de dimensiones, orientación y paleta;
- propuestas Modern, TV y Glass;
- nuevo paquete `packages/smart-engine`;
- registro de proveedores OCR intercambiables;
- pruebas unitarias para orientación, propuestas y proveedor OCR.

## Límites conocidos

OCR, QR, detección de objetos y clasificación semántica todavía no están implementados. La interfaz lo declara explícitamente.
