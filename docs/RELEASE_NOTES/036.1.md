# BMMS Graphics 036.1

## Objetivo

Convertir configuraciones completas de Scripture en perfiles reutilizables para operación real.

## Problema que resuelve

Evita reconstruir manualmente la apariencia de Scripture al cambiar entre cultos, eventos o identidades visuales.

## Cambios

- Nuevo panel **Estilos guardados**.
- Guardado persistente de perfiles personalizados.
- Aplicación de perfiles sin reemplazar el versículo activo.
- Actualización por nombre duplicado.
- Eliminación controlada de perfiles.
- Integración con composición, apariencia, degradado y Animation Engine.

## Decisiones tomadas

- El contenido bíblico queda fuera de los perfiles.
- El estado de transmisión queda fuera de los perfiles.
- Los perfiles se almacenan en el estado del proyecto, no solo en el navegador.

## Riesgos conocidos

- Los perfiles aún no se exportan ni importan como archivos independientes.
