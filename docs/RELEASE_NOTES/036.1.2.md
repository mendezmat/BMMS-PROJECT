# BMMS Graphics 036.1.2

## Objetivo

Corregir la desaparición de perfiles guardados después de modificar cualquier control de Scripture.

## Causa raíz

La cola de guardado diferido utilizaba `mergeScripturePatch()` con un objeto vacío. La función agregaba `styleProfiles: []` aunque el cambio no estuviera relacionado con perfiles. El servidor reemplazaba entonces la colección persistida por un arreglo vacío.

## Cambio

La propiedad `styleProfiles` conserva semántica de parche:

- Si el parche la incluye, se actualiza.
- Si el estado actual la incluye, se conserva.
- Si ninguno la incluye, no se envía al servidor.

## Resultado esperado

Los perfiles permanecen en el selector después de cambiar tipografía, composición, degradado, animación o cualquier otro ajuste de Scripture.
