# Scripture Style Manager

## Problema que resuelve

Permite cambiar la apariencia completa de Scripture para distintos servicios o eventos sin reconstruir manualmente cada ajuste.

## Alcance

Un estilo guarda:

- diseño y formato;
- composición y geometría;
- tipografías y colores;
- degradado;
- animaciones.

No guarda ni modifica:

- texto del versículo;
- referencia o versión bíblica;
- fuente Manual/ProPresenter;
- estado Preview/Program;
- visibilidad del output.

## Operaciones

- Guardar un estilo nuevo.
- Actualizar un estilo usando el mismo nombre.
- Aplicar un estilo sin alterar el contenido bíblico.
- Eliminar un estilo.
- Persistir los estilos dentro del estado del proyecto.
