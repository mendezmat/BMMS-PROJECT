# Visión de producto — BMMS Graphics

BMMS Graphics es una plataforma modular para crear y operar gráficos broadcast en tiempo real con vMix, OBS y otros outputs compatibles.

Su prioridad es la operación en vivo: rapidez, claridad, estabilidad y menos clics. No pretende sustituir Photoshop, Canva o ProPresenter. Los complementa y convierte contenido operativo en gráficos listos para transmisión.

## Principio rector

> BMMS no se desarrolla agregando funciones. Se desarrolla eliminando fricción del operador.

La fuente oficial para el orden de desarrollo es `PRODUCT_DIRECTION.md`.
