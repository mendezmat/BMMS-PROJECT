# Principios de producto

1. La transmisión en vivo tiene prioridad sobre la edición avanzada.
2. El contenido y el Preview tienen prioridad sobre los controles.
3. Cada clic debe estar justificado.
4. La estabilidad tiene prioridad sobre la cantidad de funciones.
5. Los módulos comparten motores cuando ello reduce duplicación sin aumentar riesgo.
6. No implementar funciones “por si acaso”.
7. No reescribir componentes estables para resolver un problema local.
8. Toda decisión importante se registra en el repositorio.
