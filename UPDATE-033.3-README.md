# BMMS Update 033.3 — Preview Fit Correction

Corrige el modo **Ajustar** del Preview de Scripture para que la salida 1920×1080 se vea completa, centrada y sin quedar cubierta por los controles de transporte.

## Cambios

- El cálculo de ajuste usa simultáneamente el ancho y el alto realmente disponibles.
- El Preview mantiene la relación 16:9.
- El canvas se centra automáticamente en modo Ajustar.
- ENVIAR/LIMPIAR/AUTO ya no se superponen sobre el Preview.
- Los modos 50%, 75% y 100% conservan desplazamiento cuando corresponde.
- No se modificó Foundation ni la lógica de Scripture/ProPresenter.
